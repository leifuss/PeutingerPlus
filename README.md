# PeutingerPlus FAQ

## What is it?

PeutingerPlus is an attempt to align three major online databases that provide URL-based identifiers for the locations depicted on the [Peutinger Map](https://en.wikipedia.org/wiki/Tabula_Peutingeriana):

* The [Pleiades](https://pleiades.stoa.org) Gazetteer of the Ancient World
* [TP-Online](https://www.ku.de/ggf/geschichte/alte-geschichte/forschung/datenbank-tp-online)
* The [_Rome's World_](https://www.cambridge.org/us/talbert/talbertdatabase/prm.html) gazetteer (Talbert 2010)

It is essentially a spreadsheet with 4 tabs: 3 look-up tables (one for each database), and a mapping table.

## What is it useful for? 

Each of the resources above provides different information about each of the locations depcicted on the map. For instance, _TP-Online_ offers extensive commentary, and it's reference IDs link to an hi-resolution online-map. _Rome's World_ provides additional commentary and some alternative interpretations, although it's own online map is currently inaccessible. _Pleiades_ provides standard URIs for the places referred to - which allow them to be associated with other geographic sources - as well as real-world coordinates, where known. By aligning this content, it is possible leverage all of these features together. One examples is my own Ravenclaw project, which explores the relationship between the Peutinger Map and the [Ravenna Cosmography](https://en.wikipedia.org/wiki/Ravenna_Cosmography).

## Can I use it?

Yes. It is available under a CC-BY license. 

## What limitations does it have?

At present it only includes references to places on the Map's itineraries. It does not include regional labels, islands, rivers and the like. This would be a useful inclusion, but requires some effort that I have limited time for at present.
